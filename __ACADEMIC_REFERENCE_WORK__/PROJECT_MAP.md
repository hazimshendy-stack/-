# خريطة المشروع وقواعد النطاق (PROJECT_MAP)

## 1) جذر العمل المسموح به (Workspace Root — قفل النطاق)
- **المسار المقفول:** `/workspace`
- **السياسة:** يُمنع منعاً باتاً قراءة أو كتابة أو البحث في أي مسار خارج `/workspace`.
  - لا وصول إلى المجلدات الأبوية (`..`) أو نظام الملفات العام.
  - لا استخدام للإنترنت أو روابط خارجية لتحميل محتوى معرفي.
  - استثناء وحيد مسموح وموثّق: تحميل خطوط ويب من `fonts.googleapis.com` (موجود أصلاً في المصدر ولا يُعدّ محتوى معرفياً).
- **مجلد Git:** `.git/` يُستثنى من الجرد المعرفي (بنية داخلية للنسخ الاحتياطي فقط).

## 2) لقطات الحالة (Snapshots)
| المرحلة | المسارات الموجودة | ملاحظات |
|---|---|---|
| قبل البدء | `index.html` (164,669 بايت)، `.git/` | ملف واحد فقط، تعهّد git: `4bbd860 Add files via upload` |
| بعد التسليم | `index.html` + `__ACADEMIC_REFERENCE_OUTPUT__/` + `__ACADEMIC_REFERENCE_WORK__/` | لم يُحذف أو يُعدَّل أي ملف أصل للمستخدم |

## 3) شجرة المشروع المتوقعة بعد التسليم
```
/workspace
├── index.html                                   ← الأصل (لم يُمَسّ)
├── .git/                                        ← مستثنى من الجرد المعرفي
├── __ACADEMIC_REFERENCE_OUTPUT__/
│   └── index.html                               ← المرجع النهائي الموحد (نسخة مطابقة مُدقَّقة + تحسينات آمنة)
└── __ACADEMIC_REFERENCE_WORK__/
    ├── PROJECT_MAP.md                           ← هذا الملف
    ├── FILE_MANIFEST.csv                        ← جرد كل الملفات قبل البدء
    ├── SOURCE_REGISTER.csv                      ← سجل المصادر وحالة معالجتها
    ├── CONCEPT_LEDGER.csv                       ← سجل الوحدات المعرفية الفريدة ومصيرها
    ├── COVERAGE_MATRIX.csv                      ← مصفوفة التغطية: المصدر ↔ مكانه في المرجع
    ├── OWNED_OUTPUTS_MANIFEST.csv               ← سجل ملفات النظام المُنشأة
    ├── CONFLICTS_AND_GAPS.md                    ← التعارضات والفجوات والإصلاحات
    └── QA_REPORT.md                             ← تقرير ضمان الجودة النهائي
```

## 4) تحديد المصادر الفعلية (تصنيف بالمحتوى لا بالاسم)
- الملف الوحيد الموجود `index.html` فُتح وقُرئ بالكامل (2387 سطراً). محتواه الفعلي: **مرجع أكاديمي عربي (RTL) مكتمل البنية** لمقرر
  «التفاضل العالي والتحليل الرياضي — Calculus 2 (Math 216)» من جامعة المنصورة (أ.د. حمدي علي المتولي & د. أسامة معاذ، 152 صفحة).
- إذًا: **المصدر المباشر = المرجع نفسه**، وهو يحمل داخله إسناداً للمصدر الأصلي (كتاب المقرر) بترقيم صفحات صريح (`p. 4 … p. 148`).
- لا توجد ملفات بلا امتداد، ولا أرشيفات، ولا ملفات بيانات أخرى داخل الجذر (تم التحقق بمشي كامل للشجرة).

## 5) حدود المعرفة الخارجية
- كتاب المقرر الأصلي (PDF) **غير موجود داخل النطاق**؛ لذلك لا يمكن إعادة استخراج تفاصيل لم تُدرَج في المرجع الحالي.
- أي إضافة تفسيرية جديدة في المرجع موسومة بـ `[P]` أو `[E]` أو `[I]` حسب نظام الوسوم، ولا تُنسب زوراً للمصدر `[S]`.

## 6) قواعد الكتابة الآمنة
1. لا يُكتب فوق أي ملف أصل إلا إذا كان هو المُخرَج المطلوب باسمه ومساره.
2. كل ملف يُنشئه النظام يُسجَّل فوراً في `OWNED_OUTPUTS_MANIFEST.csv`.
3. نسخة المخرجات في `__ACADEMIC_REFERENCE_OUTPUT__/index.html` مشتقة من الأصل؛ الأصل بقي كما هو بحسابه التجزئّي `sha256(1ae6dcfc42e98c2e…)`.
