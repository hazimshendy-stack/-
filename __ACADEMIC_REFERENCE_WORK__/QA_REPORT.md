## المشكلة المُبلَّغ عنها
كانت الصيغ الرياضية تظهر كنص خام (مثل `M = \int_V \rho\,dV`) لأن الملف لم يكن يتضمن أي محرك عرض رياضيات.

## الإصلاح المنفَّذ (على `__ACADEMIC_REFERENCE_OUTPUT__/index.html` فقط)
1. **حقن MathJax v3** (`tex-chtml.js` من CDN) مع إعداد `window.MathJax` قبل `</body>`.
2. **تطويق كل الصيغ بمعاملات LaTeX** دون تغيير المحتوى:
   - 720 صيغة مضمّنة داخل `<span class="formula">` → `\( ... \)`
   - 81 معادلة عرضية داخل `<div class="formula">` → `$$ ... $$`
   - 5 كتل `<pre><code class="formula">` → `$$ ... $$`
   - المجموع: **806 مواضع رياضية** (مطابق تمامًا لجرد `CONCEPT_LEDGER`: 806 عنصر `class="formula"`).
3. **إصلاح أخطاء LaTeX مصدرية كانت ستعطّل العرض**:
   - `rac{x}{x+1}<TAB>ight)` → `\right)` (حرف Tab كان يفسد الأمر، سبب خطأ "Extra \left or missing \right").
   - `\sin^2 <TAB>\theta` و`\sin(2<TAB>\theta)` → إزالة Tab (3 مواضع).
   - `\vec{\leftarrow}\vec{\leftarrow}` (رمز غير قياسي) → `\Leftarrow`.
   - الرمز اليوني `∈` داخل الصيغ → `\in` (مع محوّل Unicode→LaTeX احتياطي في `startup.pageReady` يعالج ∈ ≤ ≥ ∂ ∇ π θ ρ × ÷ ≠ → … قبل التنضيد).
4. **الحفاظ على الستايل**: قواعد CSS إضافية تحصر التعديل في `mjx-container` فقط بخط STIX Two Text (الخط المحدد أصلًا في القالب)، مع `direction:ltr; unicode-bidi:isolate` للعزل داخل نص RTL، ومحاذاة المعادلات العرضية وسطًا. لم تُمَسّ أي قاعدة تصميم قائمة، ولم يُحذف أو يُعدَّل أي نص عربي أو إنجليزي.

## الجولة الثانية (تدقيق 2026-11-04): بقايا نص خام + تكبير الصناديق — تم إصلاحها والتحقق منها

شكاوى المستخدم ومعالجتها:
1. **`\mathbb{R}, \mathbb{R}^2, \mathbb{R}^3` داخل جدول الرموز (خلية `<code>`)**: كانت تظهر كنص LaTeX خام لأن `skipHtmlTags` كان يستثني `pre/code`. أُصلح بإزالة الخلية من قالب `code` إلى `<span class="formula">\(...\)</span>` فأصبحت تُعرض كـ ℝ, ℝ², ℝ³ بخط STIX. وكذلك خلايا `∈ , ∉` و`\Rightarrow , \Leftrightarrow`.
2. **`Vectors in \mathbb{R}^3` و`\nabla \times \mathbf{a}` داخل وسوم `.english`**: حُوّلت إلى صيغ رياضية منضَّدة.
3. **عناوين الصناديق (box-title) الخام**: علاقة البرهان ص150، فوبيني `R = [a,b] × [c,d]`، ومقارنة غرين↔ستوكس↔غاوس — كلها أصبحت رموزًا رياضية منضَّدة.
4. **المربعات الخمسة `<pre><code class="formula">`** (مثل صندوق المتجهات i,j,k):
   - كانت **لا تُعرض إطلاقًا** (MathJax كان يتخطى `pre/code`) → الآن الـ 5/5 تُنضَّد فعليًا.
   - كانت بحجم خط ترميز صغير جدًا (12px monospace) → الآن بحجم ≈18px (أكبر من نص المتن 17px) وبخط STIX Two Text الأكاديمي نفسه، مع سطر بمقدار 2.15 للوضوح.
5. **إصلاح خلل برمجي حرج**: كان Regex الخاص بدالة `walk` في صفحة التحضير مكسورًا (`Unterminated group` console error) مما عطّل تعقيم النصوص؛ استُبدل باختبارات نصية آمنة (`indexOf('\\(')` / `indexOf('$$')`).
